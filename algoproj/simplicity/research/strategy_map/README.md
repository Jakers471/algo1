# research/strategy_map

**Purpose:** a decision-tree / neural-net style MAP of the whole strategy — see how context, the spine,
structure, the confluence GATES, `setup_arm` (ARM/DISARM) and the execution chain connect, and what's
built vs planned. Cross-cutting viz (like `chart/`), generated so it stays true to the wiring.
**Run:** `python research/strategy_map/build_map.py` → open `strategy_map.html`.
**Colors:** WIRED (green) · in research (blue) · geometry only (amber) · planned (grey). The dashed
node = the future regime/context bias layer (NOTES F14). Edit `N`/`E` in `build_map.py` as wiring changes.
